{{- /* extend_footer.html --------------------------------------------------------------------------- Emits the fingerprinted JavaScript for Obsidian authoring enhancements. - js/link-preview.js on every blog post, and on any other page kind that set hasWikilinks or hasBacklinks - js/reading-progress.js on every blog post; it returns immediately unless the browser lacks `animation-timeline: scroll()`, in which case it drives the bar that style.css links to reading-progress.html Note the deliberate asymmetry: blog posts always load it (~1.8 KB), because `partialCached "footer.html"` can render with another page's Store (see AGENTS.md trap 4), so relying solely on the per-page flags was fragile. The script itself bails immediately when the page has no `.wikilink[data-preview-title]` or `.post-backlinks-link[data-preview-title]`, so the cost on a link-free post is one cached file, no DOM work. reading-progress.js follows the same asymmetry for the same reason: emitting it only where a flag said "this page has the bar" would inherit the cached footer's page. It is a no-op in every browser that has scroll-driven CSS animations, which is most of them. Every lookup goes through `with resources.Get`, so a missing asset degrades gracefully instead of failing the whole build. Idempotency: layouts/partials/footer.html invokes this partial through partialCached (keyed by layout/kind, not by page), so page-dependent script tags are emitted from the page template first, which sets the per-page "obsidianFooterScriptsDone" flag; the cached footer invocation then renders nothing, so each page emits its own script tags once rather than inheriting the cached footer's (possibly wrong) page context. There is deliberately no diagram script: diagrams are static SVG embedded with ![[diagram.svg|Alt text]] and need no JavaScript. */ -}} {{- if not (.Store.Get "obsidianFooterScriptsDone") -}} {{- $isBlogPost := and (eq .Kind "page") (eq .Section "blog") -}} {{- $needsPreview := or $isBlogPost (.Store.Get "hasWikilinks") (.Store.Get "hasBacklinks") -}} {{- if $needsPreview -}} {{- .Store.Set "obsidianFooterScriptsDone" true -}} {{- with resources.Get "js/link-preview.js" -}} {{- end -}} {{- /* Reading progress fallback: only blog posts, and only where the CSS scroll timeline is missing. The script returns immediately when `animation-timeline: scroll()` is supported, so modern browsers pay one cached file and no listeners. */ -}} {{- if $isBlogPost -}} {{- with resources.Get "js/reading-progress.js" -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
