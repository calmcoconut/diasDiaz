The element is written from a value escaped exactly once and injected with safeHTML: the attribute name contains "src", so Hugo url-normalizes a plain {{ .Inner }} interpolation (spaces become percent-20 and an angle bracket becomes percent-3e), while an explicit htmlEscape would then be escaped a second time by the attribute context (a mermaid arrow was double-escaped).
